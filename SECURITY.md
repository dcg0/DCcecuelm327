# Política de seguridad

## Versiones compatibles

Se da soporte de seguridad, dentro de lo posible, a la versión publicada más reciente y a la rama `main`:

| Versión | Soporte |
| --- | --- |
| `main` | Sí, dentro de lo posible |
| Versiones antiguas | No garantizado |

## Cómo reportar una vulnerabilidad

No publiques detalles de una vulnerabilidad, credenciales, datos personales ni un exploit en un issue público.

Utiliza **Report a vulnerability** en la pestaña **Security** de este repositorio para enviar un aviso privado al mantenedor. Incluye, cuando sea posible:

- una descripción clara del impacto;
- los pasos mínimos para reproducir el problema;
- la versión, commit o configuración afectados; y
- una propuesta de mitigación o un parche, si lo tienes.

Si la opción de aviso privado no está disponible, abre un issue sin detalles sensibles solicitando un canal privado y espera instrucciones del mantenedor.

## Alcance

Esta política cubre el código, los workflows y la configuración mantenidos en este repositorio. No incluyas claves de vehículos, registros con datos personales ni secretos reales en reportes o pull requests.
