- ✅ Nombre: **DCtune**
- ✅ Ícono propio
- ✅ Conexión Bluetooth ELM327 / OBD2
- ✅ Lectura de sensores en tiempo real
- ✅ Gráficos y códigos de falla

## 🛠️ Desarrollo

El proyecto requiere JDK 17 y el submódulo del framework de plugins. Clona con `--recurse-submodules` y ejecuta `./gradlew build` para compilar y ejecutar las pruebas.
